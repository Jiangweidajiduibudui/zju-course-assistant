ZJU 选课助手 0.1.0-rc.1 — Windows x64 验收版

1. 将整个 ZIP 解压到本机目录，不要在压缩包内直接运行。
2. 双击 Start.cmd。启动后自动打开 http://127.0.0.1:4317。
3. 保持启动窗口开启；关闭窗口或按 Ctrl+C 停止服务。

已附带 Node.js、Chromium 和运行依赖。无需安装 Node、Python 或 Conda。
首次启动为空白工作区，没有开发者的课程、计划、登录信息或 API key。
在“连接教务”中打开独立学校登录窗口，登录并同步后新建计划。
在“模型设置”中填入自己的服务地址、模型名与 API key。key 只在本次进程中保存。
外部评价需要主动启用；摘要仅在手动点击生成时调用模型。
实际选课、退课、志愿调序仍需自己在学校页面完成。

个人数据默认保存在 %LOCALAPPDATA%\ZJUCourseAssistant。
更新程序时可换到新解压目录；不要覆盖或随意删除个人数据目录。
需要备份时使用“本机数据与备份”；需要清除资料时使用应用内清理入口。
卸载：关闭程序，删除解压目录。如同时要删除全部个人数据，再删除上述个人数据目录。

网络要求：学校服务通常需要校园网络或相应访问条件；模型与评价需要访问所选服务。
程序只监听 127.0.0.1，不向局域网开放。
如果 4317 端口已被使用，请先关闭重复启动的本程序；不要结束不认识的进程。
如需其他端口，可在启动前设置 ZJU_PORT。Windows Defender 首次检查可能使启动稍慢。
本验收包未做代码签名；它不是 Windows 安装程序。
